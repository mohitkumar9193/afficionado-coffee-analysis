The dashboard and analytics are implemented and tested with synthetic fixtures. Actual transaction data has not been supplied, so no retailer sales figures, hero products, or financial improvements are claimed.

Upload CSV or Excel data in the Streamlit dashboard to populate the analysis. Revenue is calculated as quantity × unit price; profit requires cost data.

The project is published on GitHub and the interactive dashboard is hosted on Streamlit Community Cloud.
